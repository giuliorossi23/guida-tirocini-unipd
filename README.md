# Guida Tirocini UniPD 🎓

[![ci](https://github.com/giuliorossi23/guida-tirocini-unipd/actions/workflows/ci.yml/badge.svg)](https://github.com/giuliorossi23/guida-tirocini-unipd/actions/workflows/ci.yml)
[![Website](https://img.shields.io/badge/sito_web-online-brightgreen)](https://giuliorossi23.github.io/guida-tirocini-unipd/)

Una guida pratica, chiara e operativa pensata per gli studenti dell'**Università degli Studi di Padova (UniPD)** alle prese con la burocrazia dei tirocini curriculari ed extracurriculari.

🌐 **Sito consultabile online:** [https://giuliorossi23.github.io/guida-tirocini-unipd/](https://giuliorossi23.github.io/guida-tirocini-unipd/)

---

## 📌 Indice della Guida

1. **Introduzione e Ricerca del Tirocinio**: differenze tra curriculare ed extracurriculare, canali di ricerca, convenzioni e scelta dei tutor.
2. **Attivazione (Sicurezza e Burocrazia)**: corso sulla sicurezza da 4 ore, convenzione aziendale, compilazione del Progetto Formativo su UniPD Careers ed esempi pratici.
3. **Durante e Fine Tirocinio**: variazioni in corso d'opera, copertura assicurativa, chiusura attività, firma PADES e registrazione dei CFU.
4. **Contatti e Riferimenti Utili**: orari, email e recapiti telefonici del Career Service centrale e delle segreterie stage dei singoli dipartimenti.
5. **Disclaimer e Crediti**: informazioni sulla natura del progetto e link per supportare l'autore o proporre modifiche.

## 💻 Come avviare il sito in locale

Se vuoi visualizzare il sito sul tuo computer prima di pubblicare modifiche:

### Prerequisiti
* Python 3.10 o superiore
* Git

### Installazione ed Esecuzione

1. Clona la repository:
   ```bash
   git clone https://github.com/giuliorossi23/guida-tirocini-unipd.git
   cd guida-tirocini-unipd
   ```

2. Installa le dipendenze richieste:
   ```bash
   pip install -r requirements.txt
   ```

3. Avvia il server di sviluppo locale:
   ```bash
   mkdocs serve
   ```

4. Apri il browser all'indirizzo [http://127.0.0.1:8000](http://127.0.0.1:8000). Le modifiche apportate ai file Markdown verranno aggiornate istantaneamente nel browser.

## 🤝 Come contribuire

Le procedure universitarie cambiano spesso! Se noti un link rotto, una tempistica non aggiornata o vuoi aggiungere un chiarimento utile per altri studenti:

1. Apri una **[Issue](https://github.com/giuliorossi23/guida-tirocini-unipd/issues)** per segnalare il problema o discutere un'integrazione.
2. Oppure crea una **Pull Request**:
   * Fai una copia (*Fork*) della repository.
   * Crea un branch per la tua modifica (`git checkout -b fix/aggiornamento-contatti`).
   * Committa le modifiche (`git commit -m "Aggiornato contatto stage dipartimento"`).
   * Esegui il push e apri una *Pull Request*.
